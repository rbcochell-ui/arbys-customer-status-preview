# Arby's equipment status - design preview

This is a static visual example using invented store information. It does not read FORM.com, Tableau, SharePoint, work orders, or any live request. The Inactive link button demonstrates the intended appearance; it does not revoke access to this public demo.

The repository also contains a generic encrypted status viewer at `track.html`. It has no customer project data or issued customer links. The root page remains this invented preview when opened without a project link.

Do not add customer information to this repository or use this demo as a live status link. A production customer link requires an access-checking service, an expiry and revoke control, and approved real milestone data.
